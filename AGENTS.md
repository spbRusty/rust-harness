# AGENTS.md

## Архитектура

`rust-harness` — локальный оркестратор для LLM, инструментов и MCP.

Основной цикл должен оставаться ограниченным по числу итераций и завершаться только по явному состоянию.

## Роли

- Explorer — только исследование и чтение.
- Planner — формирование короткого проверяемого плана.
- Executor — изменение проекта и выполнение необходимых команд.
- Reviewer — независимая проверка результата.

## Правила

1. Не объявлять задачу завершённой после изменения файлов без verification.
2. Ошибка verification возвращается в цикл как feedback.
3. Не увеличивать контекст бесконечно: старые результаты инструментов можно сокращать.
4. MCP подключается как слой инструментов, а не как часть логики конкретной роли.
5. Не добавлять автоматический git commit/push.
6. Новые возможности должны иметь тесты, если это возможно без внешних сервисов.
